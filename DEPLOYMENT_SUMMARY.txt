🚀 VPS DEPLOYMENT STEPS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 1: Clone Repository on VPS
────────────────────────────────────────────────────────────────────────────
$ ssh your-vps-user@your-vps-ip
$ cd /var/www
$ sudo git clone https://github.com/sa5613675-jpg/belal.git chemict
$ cd chemict

STEP 2: Run Quick Setup Script
────────────────────────────────────────────────────────────────────────────
$ sudo chmod +x quick_vps_setup.sh
$ sudo ./quick_vps_setup.sh

This script will:
  ✓ Install all dependencies (Python, Nginx, Certbot, etc.)
  ✓ Create virtual environment
  ✓ Initialize SQLite database
  ✓ Create teacher & admin accounts
  ✓ Configure systemd service
  ✓ Configure Nginx
  ✓ Start all services

STEP 3: Configure DNS (Before SSL)
────────────────────────────────────────────────────────────────────────────
Point your domain to your VPS IP:
  chemict.com         → A Record → YOUR_VPS_IP
  www.chemict.com     → A Record → YOUR_VPS_IP

Wait 5-10 minutes for DNS propagation.

STEP 4: Setup SSL Certificate
────────────────────────────────────────────────────────────────────────────
$ sudo certbot --nginx -d chemict.com -d www.chemict.com

Follow the prompts:
  - Enter your email
  - Agree to terms
  - Choose redirect HTTP to HTTPS: Yes

STEP 5: Verify Deployment
────────────────────────────────────────────────────────────────────────────
$ sudo systemctl status chemict       # Check app service
$ sudo systemctl status nginx         # Check web server
$ curl http://localhost:8006          # Test app directly

Visit: https://chemict.com
